# Ledgerly

Invoice tracking for small teams. A React web app (`src/pages`), a JSON API (`src/api`), and an export CLI (`src/cli`).

Run locally with `npm run dev` (http://localhost:5173).

## Deployments

Hosted on Vercel. `main` deploys to production at https://app.ledgerly.dev, and every branch gets a preview deployment at `https://ledgerly-git-<branch>.vercel.app`. Seeded demo data is loaded on every deployment, and the demo account needs no login.
