# Export service
Internal JavaScript service for authenticated project owners to download their existing reports. No new product decision is needed for CSV export. JSON download already exists. Follow its access behavior and error format. No new dependency, storage backend, provider abstraction, UI, or retention policy is in scope. CSV stays UTF-8 with one header row and RFC-style quoting of commas, quotes and newlines; preserve row order and the report column order. Report cells are trusted server-generated strings, never user input. Reports are bounded to 200 rows and 10 columns by the creation service. This change is downloaded directly, not persisted. Test with node --test. Implementation may choose local helpers and test names. No network service is needed to inspect or test this repo.
