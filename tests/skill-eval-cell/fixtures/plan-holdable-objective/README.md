# listingwatch

Internal ops runs Brand Watch reports on a platform brand. People often post a
link to a business listing on that platform without discussing the platform
itself, so the report fills with listing noise. Clean consumer-brand watches
are useful today and must stay that way.

Settled recommendation (already chosen; do not reopen):

- Infer entity scope and mention topology
- Compile source-aware query lanes
- Assign candidate evidence roles before metrics
- Keep broad retrieval for clean consumer brands
- Existing subscriptions adopt automatically
